TESTFLIGHT BETA DESCRIPTION
============================

App Name: MochiMeter

Subtitle: AI-Powered Calorie Tracker

---

WHAT TO TEST
------------
We're looking for feedback on:
- AI food scanning accuracy (photo & text input)
- Barcode scanning reliability
- Overall app stability and performance
- User experience and navigation
- Widget functionality

---

DESCRIPTION
-----------
MochiMeter is a smart calorie and nutrition tracker that uses AI to make food logging effortless.

KEY FEATURES:

Scan & Log Instantly
- Point your camera at any meal and get instant nutrition estimates
- Scan barcodes for accurate packaged food data
- Type a quick description like "chicken salad" and log in seconds

Smart AI Analysis
- Recognises branded foods and uses real nutritional data
- Estimates homemade meals using USDA database values
- Correct any estimate with web-verified nutrition facts

Track Your Progress
- Daily calorie, protein, carbs, and fat tracking
- Water intake logging with home screen widget
- Visual progress towards your nutrition goals

Additional Features
- Create and save custom recipes
- Set meal reminders
- Cloud sync across devices
- Dark mode support
- Home screen widgets for quick logging

PRIVACY
-------
- Your food logs are stored securely in the cloud

- You can use the app offline with local storage only
